About me
I'm Hammad Ali Tahir, a Computer Science graduate from the University of Education, Lahore (2026), currently working as an AI Trainee Engineer Intern at Analytiverse.
My project experience spans machine learning, natural language processing, RAG, and full-stack AI applications. I work primarily with Python, FastAPI, LangChain, and LangGraph, connecting retrieval pipelines and agent workflows to interfaces people can use.
I'm particularly interested in how AI systems handle difficult questions: choosing a retrieval strategy, checking the evidence, rewriting unsuccessful queries, and producing answers grounded in source documents.
What I build
- RAG systems: document ingestion, semantic and keyword search, cross-encoder reranking, query rewriting, and source citations.
- Agentic workflows: query routing, decomposition, tool integration, retrieval grading, and bounded retry loops.
- AI backends: FastAPI services, Server-Sent Events for streamed responses, authentication, and conversation storage.
- Machine learning pipelines: preprocessing, feature engineering, classifier comparison, and model evaluation.
- Evaluation and observability: retrieval and answer-quality evaluation with RAGAS, plus workflow tracing with LangSmith.
Selected projects
UOE AI Assistant
An academic assistant for the University of Education, Lahore, developed as my final-year project.
- Retrieves information from university curricula, course outlines, and rules documents.
- Combines dense retrieval with BM25 keyword search and cross-encoder reranking.
- Uses query routing, decomposition, chunk grading, and query rewriting to handle retrieval failures.
- Connects a streaming FastAPI backend to a React interface, with Supabase for authentication and conversation history.
- Uses RAGAS for evaluation and LangSmith for tracing.
Stack: Python · FastAPI · React · Pinecone · OpenAI API · Supabase · RAGAS · LangSmith

AI Legal Case Manager
A legal document classification and retrieval project built for Uraan AI Techathon 1.0, where I led a four-member team.
- Classifies judgments by case category and predicts priority using ensemble machine learning.
- Retrieves relevant judgments using sentence embeddings and a RAG workflow.
- Brings classification, prioritization, and precedent search into a Streamlit application.
Stack: Python · scikit-learn · NLTK · Sentence Transformers · Streamlit
