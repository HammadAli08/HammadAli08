## 👨‍💻 About Me: The Agent Architect

Hi, I’m **Hammad Ali Tahir**, a final-year Computer Science student specializing in ML, NLP, and LLM fine-tuning. 

I don't just write scripts; I design **Intelligent Agentic Workflows** and cloud-native AI systems that blend probabilistic AI reasoning with deterministic logic. From production-grade RAG pipelines featuring self-correcting loops to multi-agent frameworks, I build resilient, high-accuracy AI software engineered to scale.

### 🧠 Core Expertise
- **Agentic Architectures (LangGraph):** Building multi-step reasoning loops (ReAct), autonomous state machines, and live tool integrations.
- **Advanced Production RAG:** Implementing self-correcting smart retrieval loops (query rewriting, chunk grading, multi-retry mechanisms) with cross-encoder reranking and isolated vector stores.
- **Full-Stack AI Deployment:** Engineering low-latency streaming backends (FastAPI/Flask, Server-Sent Events) integrated with responsive frontends (React, Zustand) and cloud-native MLOps (Docker, Redis, Pinecone).
